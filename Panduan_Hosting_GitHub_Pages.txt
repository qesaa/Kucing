---------------------------------------------------------
LANGKAH 1 - Buat repository baru
---------------------------------------------------------
1. Buka github.com, login.
2. Klik tombol "+" di kanan atas > "New repository".
3. Repository name: Kucing
   (persis seperti ini, huruf K besar - nama ini yang jadi alamat webnya)
4. Pilih "Public".
5. Klik "Create repository".

---------------------------------------------------------
LANGKAH 2 - Upload file kucing.html
---------------------------------------------------------
1. Di halaman repository yang baru dibuat, klik
   "uploading an existing file".
2. Seret file kucing.html ke halaman itu (atau klik "choose your files"
   lalu pilih kucing.html).
3. Klik tombol hijau "Commit changes".

---------------------------------------------------------
LANGKAH 3 - Nyalakan GitHub Pages
---------------------------------------------------------
1. Di repository Kucing, klik tab "Settings".
2. Di menu kiri, klik "Pages".
3. Di bagian "Branch": pilih "main" dan folder "/ (root)", lalu klik "Save".
4. Tunggu 1-3 menit, refresh halaman Settings > Pages itu.
   Akan muncul tulisan "Your site is live at https://..."

---------------------------------------------------------
LANGKAH 4 - Buka & cek web kamu
---------------------------------------------------------
Alamatnya:
https://<username-github-kamu>.github.io/Kucing/kucing.html

Contoh: kalau username kamu "permataqesya", alamatnya jadi
https://permataqesya.github.io/Kucing/kucing.html

Cek 3 hal ini sebelum link-nya dikumpulkan ke dosen:
[ ] Kucing oren tampil di panggung (Gambar)
[ ] Klik kucingnya / tombol "Suara Meong" -> terdengar meong (Suara)
    (klik dulu halamannya, browser memang mewajibkan ada klik
     sebelum suara boleh bunyi - ini normal)
[ ] Tombol "Putar Alur Lengkap" menjalankan Gambar -> Suara -> Gerak,
    dan kucingnya berjalan menyusuri panggung (Gerak)

---------------------------------------------------------
KALAU MAU GANTI SESUATU DI WEB-NYA
---------------------------------------------------------
- Edit file kucing.html, lalu di repository klik file kucing.html >
  ikon pensil (Edit) > paste isi yang baru > "Commit changes".
  Tunggu 1-2 menit, webnya otomatis ter-update.
- Atau bilang ke Muse apa yang mau diganti, nanti file-nya diperbaiki,
  kamu tinggal upload ulang dengan cara yang sama seperti Langkah 2
  (upload file dengan nama sama akan menimpa yang lama).

---------------------------------------------------------
TROUBLESHOOTING
---------------------------------------------------------
- Halaman 404: biasanya Pages belum dinyalakan (ulangi Langkah 3)
  atau baru dibuat dan belum 3 menit. Cek juga nama repository
  ("Kucing") dan nama file ("kucing.html") sama persis dengan alamatnya,
  termasuk huruf besar/kecilnya.
- Suara tidak bunyi: pastikan volume menyala dan kamu sudah mengklik
  sesuatu di halaman (tombol / kucingnya) - suara browser hanya boleh
  mulai setelah ada klik.
- Tampilan di HP berantakan: refresh sekali; web ini sudah pakai
  viewport mobile, panggungnya menyesuaikan lebar layar.
